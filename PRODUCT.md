# TrajViz

TrajViz is a local analysis tool for people inspecting and comparing coding-agent traces. It normalizes recorded logs to frozen v1 datasets, provides source-ordered DAGs and metrics, and exports a standalone offline report. The operating goal is to understand tool calls, repeated loops, explicit file targets, failures and divergence between runs of the same task.

The primary investigation follows failure → command/output → recorded patch → later validation. A selection is a run ID plus the exact source `idx`; the same identity persists across Replay, Timeline, Graph, Compare and the shared URL. Display ordinals and action offsets remain distinct from source identity. Repeated normalized signatures retain every individual source occurrence.

Desktop reading uses 16px prose, 15px bundled JetBrains Mono evidence, 14px controls and smaller 13px directory/source metadata. Selected evidence leads at 18px. Muted Graph/Timeline category colors share a palette; selection, failure and diff remain separate meanings. The code font and its license travel with the standalone report. See the [reading and color verification](docs/research/readable-typography.md).

The current desktop direction uses white continuous workspaces, near-white neutral headers, single-pixel boundaries, dark text and blue selection; green/red retain outcome meaning. Graph remains white with no dot pattern in both appearances. A 64px single-row GitHub-style topbar contains only the existing site mark and six icon/text tabs with an active underline. It stays in normal document flow and disappears when the document scrolls down. Graph, Timeline and Replay use single-screen desktop layouts with local evidence scrolling. Compare, Analytics and Datasets use document scrolling, independent workspace heights and generous section gaps. There is no left app rail, topbar product name/breadcrumb, global search field, help/notification button or avatar. Catalog search stays available with ⌘K/Ctrl+K; appearance and dataset information move to a catalog disclosure. See the [neutral vertical workspace](docs/research/neutral-vertical-workspace.md) and subsequent [Replay refinement](docs/research/replay-layout.md), with desktop evidence at 1586×912 and 1280×800. The requested generated transparent logo is explicitly deferred by the user; the existing monochrome mark stays in use.

Whole-node silhouettes distinguish recorded categories; merged intervals use folders. Layers and Legend are closed initially; Agent activity expands within the work surface. Long content scrolls locally while the Inspector stays on screen. The Inspector has an empty prompt until a node is selected, then reveals recorded detail, patch, output or context. Desktop fullscreen has a 52px header and 350px/330px Inspector, blue primary-view selection and light-blue workspace/evidence selection. Fit uses the actual SVG viewport and safe margins; explicit source navigation keeps the complete selected node visible. Playback stays visible above a compact Agent activity disclosure. The Inspector preserves complete source IDs and missing-patch states, and exiting restores selected-node/event focus. - **Compare:** one shared A/B alignment leads, supported by three flat metrics. Step comparison begins closed unless a source is provided by the route. Patch comparison, All metrics and Run DAGs are named alternative workspaces; Agent A details, Agent B details and Key Findings are separate closed disclosures. A is green and B steel blue. Two to four same-task runs remain supported in run DAG comparison, whose fullscreen keeps Step comparison available.
- **Replay:** a compact source list supports the widest current-evidence area and a separate bottom transport row. Evidence tabs remain above the scrollable code/output. Terminal/Tests expands under the evidence in the same center column; Step details begins closed and opens at right. Above 1100px, all three columns and playback fit the screen. Source rows, code, terminal and inspection scroll locally; resizing keeps the current row visible. Auto follows available evidence until the reader pins Diff, Updated File, File Context or Output. Playback, stepping and seek update the source without resetting that view, Terminal/Tests, panel expansion or Inspector tabs. Missing evidence shows its own empty state. Secondary evidence and stage previews open on demand. Narrow layouts retain document scrolling and a reachable fixed playback bar.

Timeline fits all six source-event lanes, a searchable event log and selection-linked Inspector into one desktop screen. Long log rows and evidence scroll within their regions. Its opaque sticky labels cannot overlap event text. Compact icons and exact screen-space groups replace crowded labels; point widths never imply durations. Fullscreen includes Event Inspector. Analytics/Sankey, the dataset catalog and its filters, keyboard navigation, themes, CSV and graph PNG/SVG exports, live local refresh and single-file offline reading remain part of the product. Existing narrow-screen access remains supported; this revision does not establish a new mobile composition.

Action colors and line icons are shared across all six routes: terminal blue, reads teal, edits amber, validation green and failures red, with neutral recorded text/completion. Selection and result keep separate encodings. Failure/Edit/Validation are direct labeled jump actions; exact evidence remains readable while repeated explanations and unavailable attempts move into named disclosures. Compare presents each action name once with its actual command/path. Analytics uses shared-scale median marks and Datasets uses exact error-rate bars. See [six-route wayfinding, screenshots and verification](docs/research/visual-affordances.md).

Analytics leads with a group table and a four-item flat summary. Model/condition/outcome groups show recorded outcome distributions, median steps, error-run counts and repeated actions. Search/outcome scope, selected-group review signals, run records → Graph, bounded phase flows, exact transition tables and scoped CSV form the analysis path. Unknown pass status is separate from a recorded failure; groups can mix tasks and budgets. Graph's persistent Collapse all tool returns every detail mode to root Overview and keeps the original source evidence visible in Inspector. See [Analytics and collapse verification](docs/research/analytics-workspace.md).

Evidence boundaries are binding. V1 does not separately record message/reasoning roles, per-step agent identity or call parents, call duration, attempt count, full filesystem snapshots, cost or test pass rate. Recorded text can appear in `thought`, but that does not establish a distinct reasoning role. Show absent information as Unrecorded / 未记录; a recorded zero remains zero. Adjacent timestamp gaps are not call durations. Only explicit targets/path arguments support file targeting, which does not itself prove successful modification.

Structural graph links mean containment. Dependency links retain the existing documented file/observation heuristics. Never infer agent hierarchy or parallel branches from a visual reference. Compare alignment uses normalized action signatures, with an original-action-offset fallback for large sequences; matching and rejoining do not establish semantic equivalence or success. First divergence retains its original zero-based action offset and each side's exact source index. Patch comparison uses the last saved patch arguments with source provenance; complete final-file content is shown only when explicitly recorded.

Preserve the schema, adapters, CLI and existing data/export contracts. Reference task names, sample metrics and sample code are never product data. Personal annotations stay separate from trace evidence. Private captures, logs and credentials stay in ignored local directories; public fixtures and screenshots use synthetic data.

[DESIGN.md](DESIGN.md) defines the current visual system; the latest user-defined neutral top navigation and vertical white DAG supersede the earlier [three-page references](docs/design-references/three-page-hierarchy/) for chrome and orientation. The [earlier density work](docs/research/density-surface.md) and [dark four-page reference work](docs/research/four-reference-surface.md) remain historical records, not the current default direction.
